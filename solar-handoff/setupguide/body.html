Steps 1 and 2
Step 1 · about 2 minutes

Choose one Google account

The system saves reports in Google Drive, sends your team's emails from Gmail and reads the bills with Google's Gemini. Pick one Google account for all of it. A shared company account, such as reports@yourcompany.com, works best.

Works

Any @gmail.com address, or a company address run by Google Workspace.

Tell us first

If your company email runs on Microsoft 365, Zoho or another provider.

Step 2 · about 10 minutes

Set up your Drive folder

Everything the system creates lives in one folder in your Google Drive. Ubakel will share two files with the Google account from Step 1: the Report Template and the Run Log. When it's done, your folder looks like this:

NetSolar – Solar Reportsyou create this
Report Templateyour copy of the file we share
Run Logyour copy of the file we share
Customer Reportsyou create this
One folder per customeradded automatically
  1. In Google Drive, click New → New folder and name it NetSolar – Solar Reports.
  2. Open the Report Template we shared with you (under Shared with me). Click File → Make a copy, name it Report Template, choose your NetSolar folder, then click Make a copy.
  3. Do the same for the Run Log, naming it Run Log.
  4. Inside your NetSolar folder, click New → New folder and name it Customer Reports.
  5. Send Ubakel the links to the three items: right-click each one, choose Share → Copy link, and paste the links into an email to us.

You can rename or move these later, but please don't delete them or change the template's layout.

Steps 3 and 4
Step 3 · about 10 minutes

Get your Gemini API key

Gemini, Google's AI, reads each bill and pulls out the numbers for the report. The system uses Gemini 3.5 Flash-Lite, the model it was built and tested with. You pay Google directly for what you use, about $10 a month.

  1. Go to aistudio.google.com and sign in with the Google account from Step 1.
  2. Click Get API key, then Create API key. If asked, create a new project named NetSolar.
  3. Next to the new key, click Set up billing and add a payment card. This moves the key to the paid tier, which has higher limits and keeps your customers' bills private.
  4. Copy the key. You'll paste it into Make in Step 4.
Step 4 · about 10 minutes

Add four connections in Make

  1. In Make, open Connections from the left menu and click Create a connection.
  2. Choose the app from the table below and give it the name shown.
  3. For the three Google apps, click Sign in with Google, choose the account from Step 1, tick all the boxes and click Allow. For Gemini, paste your key and click Save.
  4. Repeat for all four, then email us to let us know.
